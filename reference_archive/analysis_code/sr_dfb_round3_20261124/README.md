## 主科学结果

- 在给定紧预测集合、已知参考和完整闭误差球下，统一可辨别存在精确阈值 d>2ε。
- 无强度下界的宽SR族共享当前子模型，全族距离为零；指定真实侧／双方强度下界产生不同解析距离。
- 对真实THINGS参考完成连续折扣域上的统一距离与点到族距离，并逐项连接旧18/24二元和11/24多元结果。
- 冻结训练参数的规则需要额外估计误差项。共同预测空间可严格保持SSE比较、剔除无关误差。
- 同77个Kern／Turner条件，统一观测类后：旧39正确方向、37当前、1对称；匹配最近族规则77个正确。目标内重拟合改变了判决问题，不是留出预测改善。
- THINGS 6+6次记录校准没有得到满足10%/20%经验错误目标、至少20条件的非空阈值；后半全部拒判。
- 折扣恢复1659/6480是已知正确方向族内的条件终点；没有折扣条件通过确定误差界。
- 未知参考必须比较受同一校准约束的两个可能世界；无界当前增益可使正参考误差下的统一分离坍缩。

所有真实数据校准都使用已知计算变换，不能据此给原参与者贴上SR方向或折扣标签。三来源各一人；复用折、嵌套通道和参数条件都不是独立参与者。

## 运行

使用Python 3.12及`requirements_analysis.txt`中的分析依赖。建议在解压后的工作副本中再运行，以保存原发布快照。

```bash
python reproduce.py --verify
python reproduce.py --full
python reproduce.py --render
```

`--verify`检查文件身份和主结果，不拟合新数据。`--full`按依赖顺序重建本轮表格与图；所有步骤都已在本轮执行，但封装后的驱动器只另做了核验模式验收，没有为重复声明成功而再跑第二遍全流程。文档渲染使用`requirements_documents.txt`，系统需Noto CJK字体。实际计算时间依硬件和数值库而异，没有依赖大规模随机模拟或虚拟被试。

全部代码使用相对项目根定位输入。重算可能改变运行时间、PDF元数据或末位浮点，不应期待归档SHA在重新生成后相同；数值一致性由`verify_release.py`检查。历史冻结清单用于追溯原发布版本。

## 数值与统计解释

连续下界使用解析不等式在float64中求值，没有向外舍入区间算术。数值AUC包络不是置信区间。经验重复差没有已知误差覆盖；已知变换的事后保证不是未知机制的事前认证。零预测和当前等价形状须归为当前类；候选名字胜出不等于方向成分存在。

所有负结果、空阈值、旧naive指标、折扣端点修订、标签/观测类修订都保留。发布材料没有把内部交叉审阅称为外部同行评审。

# A01：经验重复尺度与冻结训练模型的误差预算

2026-11-24。版本 v1 保留在 `v1_naive_radius/`，科学输入和原冻结拟合未改变。

初版评分 g/(sqrt(2)||T(B−A)||) 把两次重复差除以 sqrt(2) 当作单次噪声尺度，再代入2epsilon。这只有在额外随机误差条件下才是单次RMS近似；本轮目标Y=T D和参考预测T C之间的实际偏差来自两份测量，其差是完整 T(D−C)。此外原恢复器固定训练拟合参数，正确族参数估计误差也进入确定性充分条件。因此初版评分不对应完整的冻结恢复误差预算。

根任务与独立审阅提出并接受以下修订：

- 主经验评分：`g/(2 e_pair_train + q_train)`，其中 `e_pair_train=||T(B−A)||`，`q_train=||T_hat_true A−T_true A||`。
- 辅助 nearest-family 评分：`g/(2 e_pair_train)`。
- 初版单次尺度评分保留为明确命名的 naive 对照，不再作为主评分。
- 全空间与共同预测子空间分别报告。训练误差和 q_train 仍只是测试预算的经验预测，不具有误差上界资格。
- 事后已知变换的 `g_test > e_test + r_true_test` 与 `g_test > 2 e_test + q_test` 从一开始使用实际完整差值，未受该修订影响。

6+6记录分离实验尚未执行，也未产生后半结果；其 v2 合同在新计算前冻结主评分。v1合同保留且明确未执行。由 naive 评分产生的0/30恢复不被解释为严格分离定理的反例。

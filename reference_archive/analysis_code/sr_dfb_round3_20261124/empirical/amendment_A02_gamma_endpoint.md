# A02：折扣恢复端点的浮点一致性修订

2026-11-24；发现于最终复核、未改变方向恢复、几何参数域或 6+6 冻结规则。

折扣竞争参数域预先规定为 `|gamma - gamma_true| >= 0.2`，因此正确定义应为报告的折扣误差严格小于 0.2。原程序直接计算 `abs(error) < .2`。在二进制浮点中，0.7−0.5 被表示为略小于 0.2，而 0.5−0.3 等边界有不同舍入。这会把部分数学边界点误计为正确。

6480 个前/后向条件中，193 个拟合值位于距离 0.2 的数值端点，其中 51 个原本被计入正确。修订为 `error < .2 - 1e-12`，与排除域的闭边界一致。这使正确数从 1710 降为 1659。未报告或平坦的折扣仍记为未恢复。

所有 joined 表保留 `gamma_correct_0p2_legacy_float` 供审计，主字段 `gamma_correct_0p2` 使用修订定义。输入脚本、汇总脚本均同步修改。原先 v1 的文件已归档，未擦除。连续几何上下界不用重算；任何 oracle 折扣认证均为 0，因而这项修订不会撤销认证。6+6 实验只验证方向辨析，没有折扣终点，不受本修订影响。

此修订是数值实现与预设数学终点对齐，不是根据研究结果更换科学假设或选择更有利阈值。

# 数值求解器与解释边界的最终修订

日期：2026-11-24。范围：固定候选参考误差球求解、证明量词及 Kern 预处理说明。原始模型拟合网格、状态空间、数据划分和全部 Kern／Turner 主结果保持原样。

## 1. 独立审阅发现的实际错误

审阅者 `ekman_round2` 提供了两个能够独立复现的反例。取参考观测为零、目标观测为 $(1,10^{-9})^\top$。

- 当 $T=\operatorname{diag}(1,0)$ 时，旧版乘子方程会在极小正下端点对零奇异值计算 0／0，导致求根失败。
- 当 $T=(1,0)^\top$、参考半径为 $1-10^{-12}$ 时，解析最小残差为 $\sqrt{(10^{-12})^2+(10^{-9})^2}\approx10^{-9}$。旧版用总残差能量减去可投影能量，丢掉了 $10^{-9}$ 的正交成分，报告约 $10^{-12}$；若目标半径为 $10^{-10}$，会把不兼容误判为兼容。

这是需要修复的数值实现错误，不能以大多数常规输入通过验证为由忽略。旧代码、证明、报告、协议、摘要和受影响图的快照保存于 `v1_before_reference_ball_fix/`。独立初审证据位于 `../reviews/ekman_review_math_v1.md` 及其 JSON／Python 文件。

## 2. 修复及其范围

`reference_ball_residual` 现在对参考半径零直接返回零扰动；对正半径，仅使用严格正奇异值求约束乘子，并以最小范数无约束解给出乘子零的端点。求根按最大奇异值的平方进行尺度化。最终残差始终从 $R-T\Delta$ 直接计算，不再相减两项大能量。若最终扰动因浮点舍入略超半径，按半径做一次可行性缩放并记录该事件。

函数不把数值秩阈值当作真实零秩证据，不给经验误差半径添加概率覆盖率，也不宣称提供区间算术意义上的严格数值界。理论中的固定候选兼容性充要条件不变；其软件实现精度与统计误差模型仍需分别审查。

## 3. 有针对性的验证与真实结果影响

`verify_reference_ball_v2.py` 的 13 项解析回归全部通过：包括两个原始反例、参考半径零、精确无约束端点、接近无约束端点、零算子以及较小但为正的奇异值。最大残差绝对误差为 $3.24\times10^{-26}$。这些是解析线性代数核验，不是模拟被试。

审阅者另外独立完成 19 项解析回归，覆盖旋转后的秩一算子、多特征矩阵及算子尺度 $10^{-12}$、1、$10^{12}$；全部通过，最大残差绝对误差 $1.12\times10^{-16}$。证据在 `../reviews/ekman_recheck_math_solver.json`。

根任务以修复后的求解器重新计算原固定候选 THINGS 分析，但没有覆盖其冻结 CSV。224 条曲线兼容判断全部相同；最小残差最大绝对变化 $1.70\times10^{-12}$，直接代回残差与函数输出最大差 $2.85\times10^{-14}$。32 个经验误差倍率阈值最大变化 $5.56\times10^{-16}$。三个真实 3×2 子矩阵的独立 SLSQP 对照最大 SSE 差 $3.13\times10^{-15}$。这些变化不改变已报告精度和判断；复核文件为 `../reviews/compatibility_after_solver.json`。Kern／Turner 的主几何、γ 拟合和恢复表不使用该求解分支，因此无关计算没有重跑。

## 4. 同步澄清的数学与预处理边界

第 8 节明确区分：候选族兼容要求至少一个候选达到误差界；整族排除要求所有候选严格不兼容。下确界严格超过目标误差是充分条件。在非紧域上，所有候选不兼容但下确界恰等于误差界的情况仍然可能发生。非空紧候选集合及连续性保证最小值被取得，才使严格最小值判据与整族排除等价。有限网格本身不能提供该全局证书。

Kern 输入已使用上一轮从完整 localizer1 的无标签连续磁力计／BIO 数据估计的共有 SSP。本轮随后才划分半份；新增白化仅使用本折参考训练数据。故整条预处理并非严格嵌套于每折训练集，共有 SSP 的估计可能引入重复间依赖。报告及图注明了这一点，交叉能量被解释为固定既有处理下的重复稳定性诊断，而非已证明无偏的神经信号比例。此澄清不改变计算数值，但收窄其统计解释。

## 5. 真实滞后权重与有限基坐标的区别

独立审阅进一步要求明确矩检验的语义前提，第 7 节现给出一个解析反例族：任意 n≥5 的状态循环去均值后，真实单折扣 SR 在完整有限多项式基中的前三个等效正幂系数均有 $b_1b_3-b_2^2=-\gamma^n(1-\gamma)^2/(1-\gamma^n)^2<0$。原因是无限尾项被最小多项式折回这些坐标，而不是实际折扣混合出现负方差。五状态循环提供可直观检查的完整实例。因此矩不等式只适用于已由设计或完整模型识别的真实滞后权重；有限设计矩阵满秩本身不够。通式分子因式分解与五状态完整矩阵恒等式的符号核验在 `verify_moment_coordinates.py` 和 `moment_coordinate_checks.json`。本轮没有据此对真实参与者作机制判决，故该补充不改变任何实证结果。

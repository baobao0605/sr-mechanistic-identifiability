# A03：统一零预测增益的观测类别终点

2026-11-24，最终交叉审阅由理论分支指出并经独立重算确认。保留全部原候选标签及原评分，不改写旧结果；新增可比较的观测类别列。

旧二元函数按 F/B 候选标签判断赢家，即使赢家的预测增益为零，也可能得到“F 标签唯一正确”。新增目标内规则已经把零预测增益合并为 current。因此若直接比较旧 495/864 与新 573/864，会混用终点。

现在对旧/新规则统一执行：预测增益 α≤10⁻¹²，或拟合形状与 current 等价，则观测类别记为 current；非退化 F/B 保留其方向；两种对称写法合并为 symmetric。其余排名和原并列容差保持不变。原始 candidate-label 列完整保留。

独立核验结果：

| 集合 | 旧候选标签唯一正确 | 旧观测类可见唯一正确 | 新观测类可见唯一正确 |
|---|---:|---:|---:|
| 全部 864 二元折级条件 | 495 | 371 | 573 |
| 全部 864 多元折级条件 | 293 | 293 | 489 |
| 80 个二元充分条件通过项 | 76 | 42 | 80 |
| 77 个多元充分条件通过项 | 39 | 39 | 77 |

77 项中的旧 raw 候选标签为 39 唯一正确、37 并列、1 唯一错误；37 个并列全部合并为 current-only，另 1 个为 symmetric。统一观测类别后不存在剩余并列，也没有选成相反方向。它们应解释为 39 有可见方向证据、37 无可见预测成分、1 对称解释。不能把这 38 项叫作 38 次前后方向误判。

80 项中的旧 4 个未唯一正确标签含 3 个另一方向标签和 1 个标签并列，但这 4 个以及另 34 个“标签正确”的赢家都没有可见预测成分；统一后为 42 可见正确、38 current-only。

四折汇总的 216 条方向条件中，旧二元 145 条、多元 74 条唯一正确都至少有一折具有可见预测成分，因而汇总恢复计数及基于它们的 AUROC/跨数据阈值不受此修订影响。连续几何、误差、充分条件通过数均未改变。

证据为 `audit_observed_classes.py`、`observed_class_audit.csv`、`observed_class_aggregate_audit.csv`、`observed_class_summary.json`。最终报告和图使用统一观测类为主要终点，同时给出 raw 标签审计。

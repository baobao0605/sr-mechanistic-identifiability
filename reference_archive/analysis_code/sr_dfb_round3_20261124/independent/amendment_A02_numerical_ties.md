# A02：合并数值运算制造的分数并列

2026-11-24，独立终审发现并在最终报告前修正。连续距离、原模型拟合、oracle 不等式以及所有条件记录均未改变。

初版探索性阈值以浮点数的逐位不同作为不同分数。相对 margin 在部分条件下理论上正好等于给定预测强度（例如 1），但 RSS 与范数相除产生约 10⁻¹⁵ 的算术误差；阈值 1.000000000000001 因而错误地拆开了应当并列的条件。对该阈值不能作科学解释。

修订：所有用于描述性 AUROC 和跨数据源经验阈值选择的分数，统一四舍五入至小数点后 12 位，再计算排名和阈值。该精度远小于连续几何的 2×10⁻⁴ 区间宽度，规则对全部指标相同，与结果标签无关。真实条件 CSV 中仍保留完整计算数值。

初版代码、结果和散列保存在 `v1_raw_numeric_ties/`。它们保留为审计记录，不作为最终主结果。此修订不改变 77 条多元及 80 条二元 oracle 判别条件，也不改变任何旧恢复结果。跨数据源阈值属于事后探索，不因本次数值处理获得预注册资格。
